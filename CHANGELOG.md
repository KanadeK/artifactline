# Changelog

All notable changes to this project are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-08-30

### Added

- Offline producer/consumer modeling for first-party GitHub Actions artifact steps.
- Eight stable rules covering collisions, missing handoffs, dependency edges,
  empty upload policies, hidden-file scope, download-all drift, and dynamic uncertainty.
- Terminal, deterministic JSON, and SARIF 2.1.0 reports with source locations.
- Stable `0`/`1`/`2` exit contract and optional strict warning gate.
- Composite GitHub Action, Windows/Linux CI, and tag-driven release automation.
